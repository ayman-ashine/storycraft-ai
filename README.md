# StoryCraft AI

StoryCraft AI is an intuitive AI tool designed to help users generate stories effortlessly. It offers customizable options to tailor the narrative with ease, making the creative process seamless and enjoyable.

## Features
- AI-powered story generation
- Customizable storytelling options
- Various tools to enhance creative writing
- Responsive web-based application

## Getting Started
### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/ayman-ashine/storycraft-ai.git
   ```
2. Navigate to the project directory:
   ```bash
   cd storycraft-ai
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application
Start the development server:
```bash
npm run dev
```
The application will be available at `http://localhost:3000`.

## Technologies Used
- **Framework:** Next.js
- **Animation:** Motion
- **Hosting:** Web-based only
- **Fetching** axios
- **Date Formatting**: date-fns
- **State Management**: Zustand
- **AI API**: @google/generative-ai
